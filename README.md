## 📖 Project Overview
This project was a major milestone in my journey toward mastering the "Front" of Frontend development. Using the Ben 10 universe as a content base, I engineered a multi-page Wiki to test my ability to maintain **design consistency** across a large set of data. 

The goal wasn't just to make it look good, but to understand how to structure CSS so that every character page felt like part of a unified "Omnitrix" interface.

## 🛠 Engineering Highlights (CSS Focus)
- **UI Components:** Implemented functional modals for Login/Signup and a hero carousel, mastering the bridge between custom CSS and the Bootstrap framework.
- **Visual Hierarchy:** Crafted a systematic card layout for 10+ aliens, balancing typography and imagery to ensure high readability.
- **Navigation Logic:** Built a responsive, multi-level dropdown navigation system to handle deep content categorization.
- **Layout Management:** Utilized a mix of CSS Grid and Flexbox principles to ensure the "Encyclopedia" feel remained intact across various viewport sizes.

## 🧠 What This Taught Me
Building a "hardcoded" Wiki is a challenge in discipline. Without a backend, I had to be extremely organized with my HTML and CSS classes:
1. **DRY Principle:** I learned to write reusable CSS classes so that updating the "Alien Card" style once would reflect across all 10 profiles.
2. **Component Thinking:** This was my first step toward thinking in "components"—breaking the UI down into a Navbar, a Footer, a Sidebar, and a Content area.
3. **The User Flow:** I focused on the UX of a "Wiki," ensuring that "Continue Reading" buttons and links felt intuitive.

## 🚀 Tech Stack
- **Structure:** HTML5 (Semantic & Accessible)
- **Styling:** CSS3 (Custom Properties, Transitions, Layouts)
- **UI Framework:** Bootstrap (Modals, Sliders, Grid System)
- **Hosting:** GitHub Pages
